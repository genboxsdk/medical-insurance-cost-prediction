# Medical Insurance Cost Prediction

## Overview

This project predicts medical insurance charges using Machine Learning models 

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn

## Features

- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Feature Engineering
- Multiple Regression Models
- Hyperparameter Tuning
- Model Comparison
- Interactive Insurance Cost Prediction Dashboard

## Models Used

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- SVR
- KNN Regressor
- Gradient Boosting Regressor

## Evaluation Metrics

- MAE
- MSE
- RMSE
- R² Score

## How to Run

1. Install requirements
2. Open the notebook
3. Run all cells
4. Use the dashboard to predict insurance costs
